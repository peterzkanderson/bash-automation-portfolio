# Bash Automation Portfolio

A collection of production-ready Bash scripts and automation tools built to demonstrate Linux administration, API integration, and DevOps workflows.

## Projects Included

* `01-fundamentals` : Basic greeting and interactive logic scripts.
* `02-system-info` : System diagnostics and disk usage tools.
* `03-weather-app` : API-driven weather fetcher using `curl`, `jq`, and `bc`.
